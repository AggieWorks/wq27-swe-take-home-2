# Dibs Frontend

Tech Stack:

- Next.js (React)
- TypeScript
- Tailwind

## Prerequisites

Software to be installed:

1. [pnpm](https://pnpm.io/) (version 10 or higher)
2. [Node.js](https://nodejs.org/) (version 22 or higher)

## Getting Started

1. Install packages

   ```bash
   pnpm install
   ```

2. Run development server

   ```bash
   pnpm run dev
   ```

3. Format and lint code

   ```bash
   pnpm run fix
   ```

4. Run all tests

   ```bash
   pnpm run test
   ```
